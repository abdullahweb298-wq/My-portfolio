# Abdullah Tanveer — Portfolio Website

A responsive, dark futuristic portfolio built with plain HTML, CSS and JavaScript. Your profile image is already included.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best results, use VS Code with the Live Server extension and choose **Open with Live Server**.

## Customize before publishing
Open `index.html` and search for:
- `YOUR_EMAIL@example.com` — replace with your real email.
- `https://github.com/` — replace with your GitHub profile.
- `https://www.linkedin.com/` — replace with your LinkedIn profile.
- `Your Project Name` — replace with your real project names.
- Project descriptions, technology tags, and each `href="#"` demo/source link — replace with actual links.
- Skills section — remove skills you don't use and add your own.

Your photo is at `assets/abdullah.jpg`. Replace that file with another photo using the same filename if you want to change it.

## AI assistant note
The included assistant is a front-end demo with scripted replies. It is not connected to a live AI model. For real AI responses, create a backend endpoint and call an AI API from the server; never expose a private API key in `script.js` or browser code.

## Publish
You can host this static site on GitHub Pages, Netlify, or Vercel. Upload the complete folder, including the `assets` directory.
